# Pixoin - pixel art game

A small, cozy pixel game where you can draw animals, app icons, clothes, drinks, fish, food, swords, and more.

You can also add your own images and turn them into pixel art.

# How to play

Windows

- download the Pixoin-win-v1.x.zip
- extract the ZIP archive
- open the extracted folder
- run Pixoin.exe

Linux

- download the Pixoin-linux-v1.x.zip
- extract the ZIP archive
- open the extracted folder
- run Pixoin

No installation required.
